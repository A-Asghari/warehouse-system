- `sqlserver` connector → Sepidar ERP, server 192.168.0.12\Sepidar, database Sepidar01 (read-only, see feedback-sepidar-read-only).
- `sqlserver2` connector → fingerprint attendance (clock in/out) system, server 192.168.0.8\io, database GBgVKH.
- In Sepidar, "انبار خط" means «انبار بخش مونتاژ (نیمه‌ساخته)» and «انبار بخش واير (نیمه‌ساخته)»; most raw-material output flows there before consumption.
