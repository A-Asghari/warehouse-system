# نسخه موبایل (PWA) — راهنمای نصب

سه فایل داخل پوشه `mobile/` هستند. هیچ‌کدام به `public/index.html` یا `server.js` دست نمی‌زنند.

## ۱. کپی
کل پوشه `mobile` را داخل `public` پروژه بگذارید:

```
WarehouseSystem/
  public/
    index.html        ← دست‌نخورده
    logo.png
    logo-transparent.png
    mobile/           ← این پوشه را اضافه کنید
      index.html
      sw.js
      manifest.webmanifest
      icons/            ← آیکون‌های نصب
```

سرور شما `public` را به‌صورت استاتیک سرو می‌کند (`express.static('public')`)، پس هیچ تغییری در `server.js` لازم نیست.

## ۲. باز کردن روی گوشی
در کروم اندروید:

```
http://192.168.0.16:3000/mobile/
```

(اگر IP سرور عوض شد، لازم نیست چیزی را ویرایش کنید — اپ موبایل آدرس سرور را از خودِ URL می‌خواند، برخلاف نسخه وب که `API_URL` در آن هاردکد است.)

## ۳. نصب
منوی کروم ← «افزودن به صفحه اصلی». آیکون VSMART روی صفحه اصلی می‌آید و اپ تمام‌صفحه و بدون نوار آدرس باز می‌شود.

## چه چیزی کار می‌کند
- ورود با همان کاربران `db.json` (نشست در `localStorage` با کلید `warehouseMobileUser` — جدا از کلید نسخه وب).
- موجودی بخش کاربر (نقش‌های مدیر/سرپرست/انباردار همه بخش‌ها را می‌بینند).
- ثبت تولید با پر شدن خودکار مواد از `/api/bom/suggest` و ثبت سند مصرف برای هر ماده — همان ترتیب نسخه وب.
- ثبت مصرف، خروج به بخش، ضایعات، کسری و اضافات.
- تایید و رد اسناد: تایید گیرنده، تایید انباردار، تایید سرپرست برای ضایعات و تعدیل — دقیقاً با همان قواعد دسترسی سرور.
- گزارش‌ها: کاردکس، عملکرد روزانه، تاریخچه.
- هر ۶ ثانیه `/api/data-version` چک می‌شود؛ فقط در صورت تغییر، داده دوباره خوانده می‌شود.

## محدودیت‌ها
- سرویس‌ورکر فقط پوسته اپ را کش می‌کند و دامنه‌اش `/mobile/` است؛ درخواست‌های `/api/` هیچ‌وقت کش نمی‌شوند. یعنی بدون شبکه، اپ باز می‌شود ولی داده ندارد.
- آیکون‌ها در `mobile/icons/` هستند: نسخه `maskable` حاشیه امن دارد تا اندروید وقتی آیکون را دایره یا مربع‌گرد می‌کند لوگو را نبرد. اگر بعداً نشانه مربعی اختصاصی طراحی کردید، فقط همین چهار فایل را جایگزین کنید و شماره `CACHE` در `sw.js` را یک عدد جلو ببرید.
- بیرون از شبکه محلی کار نمی‌کند (محدودیت خودِ سرور، نه اپ).
- تب‌های مدیریتی (سال مالی، تعریف محصول، BOM، کاربران، بکاپ، همگام‌سازی سپیدار) عمداً در موبایل نیستند — همان‌طور که در نسخه وب هم فقط برای مدیر است و روی دسکتاپ معنا دارد.
